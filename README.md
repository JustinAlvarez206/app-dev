# Interstellar

A team of explorers travel through a wormhole in space in an attempt to ensure humanity's survival.

- **Release Year:** 2014
- **Genre:** Sci-Fi, Adventure, Drama

### Why I Like It
1. Emotional and thought-provoking storyline.

3. Iconic soundtrack composed by Hans Zimmer.
